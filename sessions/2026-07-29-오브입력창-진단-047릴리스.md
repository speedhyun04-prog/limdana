# [세션] 2026-07-29 배포판 오브 입력창 안 뜸 진단 + 0.4.7 릴리스

- 날짜: 2026-07-29
- 프로젝트/주제: 아호비(dev\ahovye) 배포판에서 오브 입력창이 안 뜨는 문제 원인 파악, 재발방지 수정, 0.4.7 릴리스·커밋

## 결정 사항
- 0.4.6 배포 빌드 자체는 정상으로 판정. dist\Ahovye\Ahovye.exe --orb 를 개발기에서 직접 띄우고 Win32(EnumWindows+mouse_event)로 실제 클릭해 입력창(336px OrbChatPanel)이 뜨는 것을 확인했다.
- 유력 원인: 구버전(0.4.5, 1단계) 오브가 창 틀 없는 백그라운드 프로세스라 설치 마법사의 CloseApplications(Restart Manager)가 못 닫고 살아남음. 제어 포트 8768을 계속 쥐고 있어 새 에이전트가 orb_alive() 판정으로 새 오브를 안 띄우고, 화면의 오브는 구버전 메모리 코드(좌클릭=스튜디오 열기, 입력창 없음).
- 재발방지는 설치 마법사(ahovye_setup.iss) 쪽에 넣는 것이 맞다. 업데이트 러너(updater.py)는 구버전이 만든 것을 쓰지만, 러너가 실행하는 것은 새 설치판이므로 iss 수정만으로 0.4.6→0.4.7 업데이트부터 바로 효력.
- 보스 화면의 입력창(대기·AHOVYE·opus, 모델 드롭다운)은 개발기 전용 HUD(jarvis)이고, 배포판 오브 입력창은 단순 패널(아호비 제목 + 입력 한 줄 + ↺⤢✕)로 서로 다르다는 점을 보스에게 안내함.

## 진행 상황 (완료)
- installer/ahovye_setup.iss 에 [Code] PrepareToInstall 추가: 파일 복사 전 taskkill /F /IM Ahovye.exe /T 로 에이전트/셸/오브 전부 정리 + 1초 대기.
- python installer\release.py --bump patch 로 0.4.7 빌드·게시 완료 (PyInstaller + ISCC, 약 20분 소요. Inno LZMA2 압축이 오래 걸리므로 감시는 넉넉히).
- web/static/dl/latest.json 이 0.4.7 (sha256 b6b72039..., size 149,849,812) 로 게시됨. 노트: "설치 전 기존 프로세스 정리 - 구버전 오브가 남아 입력창이 안 뜨던 문제 재발방지".
- git 커밋 73068c4 (main): VERSION, installer/ahovye_setup.iss, web/static/dl/latest.json 3개 파일만. 다른 세션의 메신저 작업 변경분(chat_common.py, web/server.py, rooms 계열, messenger_mcp.py 등)은 워킹트리에 그대로 남김.
