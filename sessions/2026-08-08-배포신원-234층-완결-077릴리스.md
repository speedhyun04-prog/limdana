## 결정 사항
- **G3(게시 전 스모크)**: pre-push 훅/CI와 검사 내용은 100% 같지만 길목이 달라 여전히 필요. 구현은 tools/ci_check.py 재호출 한 줄(목록 갈라짐 금지). 위치는 G1 다음, [a] 앞.
- **G4(원격 존재)**: 판정 대상은 HEAD가 아니라 "배포될 커밋"(--skip-build는 스탬프 커밋). fetch 없이 로컬 remote-tracking(`git branch -r --contains`)으로만 판정. skip-build에도 성립하는 유일한 관문.
- **2층 A(목록 자동화)**: 아키텍트 설계(§8-2) 선행. 루트 선언(PAYLOAD_DIRS/FILES/PRUNE) + `git ls-files` 파생. 미추적 쓰레기 구조적 차단, git 부재는 PayloadError(침묵 팽창 금지). G1 매칭은 파일 목록 → 선언 루트 기준으로 변경("커밋 잊은 새 모듈"도 차단). 전환 시점 동봉 집합 변화 0 실측.
- **2층 B(G6)**: 빌드 후 dist 목록 대조([c]→G2→G6→[c2]). G2는 내용, G6는 목록. 과잉 검출은 전용 폴더만(dist 루트는 PyInstaller 런타임이라 누락만).
- **2층 C(?v= 캐시버스터)**: 서빙 시점 치환(web/staticver.py 신규, index·/wfboard 라우트). 토큰은 파일별 mtime. 수동 갱신 규칙 폐지.
- **4층**: CHECK_INTERVAL_SEC 24h→1h(설치판에 구워지므로 ≤0.7.6은 다음 업데이트 후부터). /admin 반영률 "반영 N/M (P%)" = 최종 배지 '최신' 행 비율(빌드 미보고는 버전 같으면 반영으로).
- 우회 추적 구멍 보완: --skip-build 재게시는 스탬프를 안 찍으므로 forced 표식을 latest.json에도 남긴다.
- notes.txt(릴리스 노트 입력)는 gitignore — 릴리스마다 dirty 스탬프를 유발해서.
