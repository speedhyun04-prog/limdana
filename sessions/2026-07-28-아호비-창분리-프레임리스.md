# [세션] 2026-07-28 아호비 창 분리 개편 (로그인 게이트, 상주창+메신저, 프레임리스)

- **날짜**: 2026-07-28
- **프로젝트/주제**: 아호비 스튜디오 창 구조 대개편. 보스 스펙 "1 로그인 → 2 아호비 상주창 등장 → 3 동시에 메신저 창 등장"을 설계·구현하고 후속 UI 지시 다수 반영.

## 결정 사항
- 창 2개 분리 확정: 상주창 = AI 컴팩트(420px 도킹 컬럼), 메신저 창 = 사내대화 별도 창(/?msn=1). 설계 문서 먼저 작성 후 승인받아 구현 (단일 출처: dev\ahovye\docs\ARCHITECTURE_WINDOWS.md).
- 조직도는 메신저 창 오른쪽 옆 별도 창(/?org=1)으로 (보스: "왼쪽에서 오른쪽으로").
- 모든 창 등장/확장은 슬라이딩 도어 연출(240ms, 위치만 이동), 창 전부 프레임리스(단, /admin 창은 일반 프레임 유지).
- 타이포 위계: 주제(패널 제목) 17px/800, 소주제(섹션 라벨) 11px/700 회색 통일. 단, 조직도 트리는 보스 제안대로 폰트 통일 + 간격/들여쓰기(팀 20px, 부문 간 16px)로 위계 표현.
- 대화창은 목록·AI 화면보다 한 단계 깊은 라벤더(3단계 색 위계), 헤더/입력줄 레이어 섀도로 입체감.
- 채팅 컬럼 헤더는 애플식 2단(1줄 제목, 2줄 액션 버튼)으로 고정 (버튼 잘림 방지).

## 진행 상황 (전부 라이브)
- 셸(combine/shell.py): login/resident/full 상태기계. 가드 8767 명령 추가: /login-ok /logged-out /msn /move /min /quit /resize/8방향. 메신저·조직도 창 단일 보장, 슬롯 배치(_next_slot), msn 지오메트리 기억, DWM 라운드/그림자 복원(apply_frameless_chrome), startSystemMove/Resize.
- 웹: msn.js 신규(msnInit·orgWinInit), core.js에 POP_MSN/POP_ORG/msnOpen/ahoWinDrag/ahoWinResizable(Zones), boot.js 분기, shell.js에 view-resident·guardPing·#winCtl(본창 ─/✕)·헤더 드래그, 알림 중복 방지(msn-open 방송 시 본창 토스트 양보).
- 버그픽스 5건: 통합검색/캡처바 가운데 정렬(login-in 키프레임 to{transform:none}이 translateX 정렬을 덮어씀 → margin:auto로), 메신저 창 방 분리 실패(_PopupCandidatePage에 createWindow 없음 → 추가), 재기동 시 로그인 창 안 보임(Start-Process -WindowStyle Hidden의 SW_HIDE가 첫 Qt 창에 상속 → 플래그 금지), 세션 없는 창에서 닫기/이동 미배선(제어 배선을 토큰 검사 앞으로), 헤더 버튼 잘림(2단 헤더).
- 검증: 오프스크린 스모크 win_smoke.py 22/22(상태기계·슬롯·멱등·상태파일 호환), 브라우저 DOM 검증 다수. 서버(web/server.py)는 무변경이라 재시작 불필요, 정적 파일은 ?v= 갱신(20260728i까지).
