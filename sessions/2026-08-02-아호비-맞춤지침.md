# [세션] 2026-08-02 아호비 계정별 맞춤 지침

- **날짜**: 2026-08-02
- **프로젝트/주제**: ahovye 웹 스튜디오, 계정별 아호비 맞춤 지침(개인 시스템 프롬프트) 기능

## 결정 사항
- 맞춤 지침 입력은 채팅 명령이 아니라 **설정 화면(설정 모달 '아호비' 탭)** 방식으로.
- 지침은 users.json 계정 항목(custom_prompt)에 저장, 상한 2,000자, 빈 값 = 삭제.
- 주입은 기본 시스템 프롬프트 **맨 뒤에 append** (앞부분 공통 유지로 프롬프트 캐시 보존)
  + "기본 규칙(정체성·안전·회사 정책) 우선" 경계 문장 포함. 매 호출 새로 읽어 저장 즉시 반영.
- 저장 버튼 없이 **카톡식 자동 저장** (입력 멈춤 0.8초 + 블러 시, 동일값 재전송 안 함).
  모달의 보라색 주 버튼은 '닫기' 하나로 통일 (보스 오더: 버튼 위치 통일성, 카톡 참조).
- 오브(데스크톱)·음성(SYSTEM_PROMPT_VOICE) 쪽 맞춤 지침 적용은 **다음 단계로 보류**.
