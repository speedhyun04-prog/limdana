# [세션] 2026-08-02 아호비 사이드바 접힘 짤림(.sec-head 8px)

**날짜**: 2026-08-02
**프로젝트/주제**: 아호비 스튜디오 웹 — 접힌 사이드바에서 `.sec-head` 가 `.side-scroll` 밖으로 8px 나가는 짤림(UI_GUARDRAILS §5.5 감사) 수정

## 결정 사항

- **원인은 52px 레일이 아니라 폭 0 레일이었다.** 보스 리포트는 "접힘(52px)"으로 지목했지만,
  `#side` 52px 상태(창 폭 >760px)는 수정 전에도 감사 0. 실제로 걸리는 곳은
  `@media (width<=760px)` 안의 `body.side-closed #side{width:0}` 경로다.
- 메커니즘: `box-sizing:border-box` 여도 요소는 **자기 패딩보다 좁아지지 않는다.**
  `#side` 가 0px 인데 `.side-scroll{padding:0 8px}` 이 16px 를 남기고,
  `width:100%` 인 `.sec-head` 가 8~24px 에 놓여 클리핑 박스(0~16) 밖으로 정확히 8px.
  섹션 3개(프로젝트/커넥터/대화 내역)라 감사 항목도 3건.
- 가드레일 §5.5 "고정폭 안쪽 래퍼 + 모드별 바깥 폭 오버라이드는 짝으로 다닌다"의
  **패딩 판본**. 보스의 1순위 패턴 짐작이 맞았고, 위치만 달랐다.
- 그 폭에서 `#side` 는 `overflow:hidden` 인 0px 상자라 **눈에 보이는 짤림은 없었다.**
  실익은 (a) 감사 0 회복, (b) 폭 0·border 0 인데도 홀로 본문 위에 번지던
  `box-shadow:20px 0 60px` 제거.
