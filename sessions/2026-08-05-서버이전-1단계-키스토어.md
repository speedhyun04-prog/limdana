## 결정 사항
- 클로드 키 봉인 방식: **마스터 키파일(secrets/keystore.key) + AES-256-GCM 단일 경로** 채택 (설계: docs/ARCHITECTURE_KEYSTORE.md). DPAPI 유지 이중 백엔드 기각(리눅스 CI가 윈도 경로를 영영 못 봄), AWS KMS 보류(승격 신호: AWS 계정 다인 운영·스냅샷 계정 밖 반출), Vault 금지.
- 암호문 포맷 "v2:" + base64(nonce12+ct+tag), AAD=uid(바꿔치기 방지). 구세대(DPAPI) 암호문은 복호 시도 없이 None.
- 이관 UX: **로그인 리씰 셀프힐** — 로그인키=API 키 원문이라 새 서버 첫 키 로그인 순간 자동 재봉인. 사원 무자각, 공지 불필요. 키파일 분실 사고도 같은 메커니즘으로 복구.
- 리씰 판정은 설계 §3.3(접두사)에서 "get_claude_key가 None이면"으로 확장 구현(§5 키파일 분실 복구 약속을 덮기 위해, 문서 반영됨).
- EBS는 암호화 볼륨으로 생성(키파일이 스냅샷에 포함되므로 필수, KEYSTORE §6.2).
- systemd 유닛은 루프백 바인딩 유지(Caddy 동일 박스 전제) — SERVER §6의 0.0.0.0 서술을 이 방식으로 갱신.
