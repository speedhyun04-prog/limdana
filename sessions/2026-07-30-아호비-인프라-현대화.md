## 결정 사항

- **저장소를 SQLite 로 확정**. 방 메타는 JSON 통째로(`meta` 컬럼), 메시지만 행 분리.
  호출부 계약(`load_all()` dict 모양)은 유지 → rooms_api 저장 호출부 12곳 무변경.
- **SSE 는 "이벤트=신호, 데이터=기존 경로"**. 방 내용을 스트림으로 보내지 않는다.
  렌더 코드 두 벌이 생기는 것을 피하려는 선택. 되돌리기는 script 한 줄 삭제.
- **publish 훅 대신 DB 스냅샷 비교(1초)**. 지연 0 을 포기하고 워커 다중화 안전성을
  택했다. 훅은 나중에 *추가* 가능(스냅샷 비교는 안전망으로 남긴다).
- **EventSource 대신 fetch + ReadableStream**. EventSource 는 커스텀 헤더 불가 →
  토큰을 쿼리스트링에 넣어야 하는데 접근 로그에 남는다.
- **무응답(좀비) 서버는 watchdog 이 강제 킬하지 않는다**. 진행 중 전송을 끊고,
  run_server 안에 재시작 루프가 이미 있다. 기록만 남기고 사람이 판단.
- **GitHub 리포는 private 필수**. 추적 파일에 실제 이메일이 하드코딩돼 있다.
- **커밋은 논리 단위 4개 + CI 수정 1개**. 다른 세션 미커밋 작업과 섞이지 않게 분리.
