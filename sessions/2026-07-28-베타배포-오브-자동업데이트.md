- **날짜**: 2026-07-28
- **프로젝트/주제**: 아호비 베타 배포 전체 사이클. 설치판 0.4.2 배포 → 애플 지원·가이드 3종 → Defender 예외 → 상주 오브 1단계(0.4.3) → 자동 업데이트(0.4.4 동봉)

## 결정 사항
- 애플 배포는 네이티브 앱 대신 **웹 앱 방식이 공식 경로** (윈도우에서 맥 크로스컴파일 불가). 아이폰 "홈 화면에 추가", 맥 Safari "Dock에 추가".
- 상주 오브는 **서버 중계형**으로: 1단계 클릭형(음성 없음) 완료, 2단계(서버 중계 음성)는 설계만 (docs/ARCHITECTURE_ORB.md).
- 자동 업데이트는 클로드 앱 방식(확인→백그라운드 다운로드→재시작 시 무인 적용). **0.4.4 설치자부터 동작**, 0.4.3 이하는 수동 재설치 1회 필요.
- 릴리스는 `release.py` 한 명령으로 일원화. 보스는 "릴리스해줘"만 하면 됨 (관리자 권한 불필요).
- .gitignore의 web/static/dl/은 exe만 제외 (가이드 HTML은 커밋).
- Defender 예외 등록은 보안 설정이라 클로드가 직접 실행하지 않음 — 스크립트 제공 + 보스 직접 실행 방식.
