# [세션] 2026-08-05 감시자 배터리 결함 · 0.7.5 릴리스 · dirty 신호 복구

**프로젝트/주제**: 아호비. 개발기 셸을 내리고 감시자를 검증하다 "등록됐는데
실행은 안 되는" 결함을 잡았고, 고쳐서 0.7.5 로 게시한 뒤, 그 진단을 도와준
빌드 스탬프의 `dirty` 신호까지 손봤다.

## 결정 사항

- **감시자 태스크는 XML 정의로 등록한다.** `schtasks` 스위치로는 배터리 설정을
  끌 수 없다. 스위치를 쓰는 한 같은 결함이 재생산된다.
- **이미 잘못 깔린 태스크는 앱이 스스로 고친다.** `ensure_task()` 가 "없으면
  만든다"에서 "있어도 설정이 틀렸으면 다시 만든다"로 바뀌었다.
- **`dirty` 판정에서 릴리스 도구 자기 파일은 뺀다.** 정상 경로에서도 참인
  플래그는 신호가 아니다.
- 0.7.4 는 다른 세션이 게시했고 감시자 수정이 빠져 있었다. **0.7.5 로 덮었다.**

## 진행 상황 (완료)

**1. 개발기 셸 정리**
`studio_web.pyw` 종료. 8766·8767 을 설치판에 돌려줬다.

**2. 감시자 결함 규명** (실측 진단)
selftest 는 통과하는데 죽여도 45초간 안 살아났다. 태스크는 등록돼 있고
`schtasks /query` 정상, 마지막 결과 0, **그런데 프로세스 생성 자체가 없었다.**
원인 둘:
- `agent_state.json` 의 `user_quit` 이 참으로 남아 있었다(계약대로 동작한 것).
- **`DisallowStartIfOnBatteries=true`** — `schtasks /create` 스위치의 기본값.
  사원 PC 는 대부분 노트북이라 전원을 안 꽂은 동안 감시자가 통째로 잠든다.

**3. 수정** (커밋 `fdc0a9d`)
`_task_xml`/`_create_task` 로 XML 등록 전환(배터리 두 항목 해제 +
StartWhenAvailable + ExecutionTimeLimit 5분). `task_battery_blocked()` 로
자가 교정. selftest 에 배터리 검사 추가. 설계는 `docs/ARCHITECTURE_WATCHDOG.md`
§5-1, §5-2.

**4. 릴리스 0.7.5** (커밋 `7b7e893`)
0.7.4(11:12 빌드)에 수정이 빠진 것을 **BUILD.json 파일 해시로 판정**했다.
0.7.5 는 저장소 소스와 dist 의 `client/watchdog.py` 해시가 일치한다.
안내 페이지 3개(install·intro·apple) 버전 표기도 함께 올렸다(릴리스 도구가
안 건드리는 파일).

**5. 실증** (설치판 0.7.5 로)
- 무인 설치 → 에이전트 기동 → 태스크가 새 정의로 재등록
- 태스크를 0.7.3 방식으로 되돌림 → 재기동 → **2초 만에 자가 교정**
  (로그 "감시자 태스크 배터리 제한 교정")
- 손대지 않은 5분 정기 실행으로 자동 복구(14:15:01)
- **배터리 상태(전원 뽑음)에서도 정기 실행 복구 성공(14:20:01)** ← 최종 근거

**6. `dirty` 신호 복구** (커밋 `541f726`)
릴리스 도구가 판정 전에 자기 파일을 고쳐서 `dirty` 가 항상 참이었다.
`buildstamp.dirty_paths(root, ignore)` 신설(git pathspec `:(exclude)`),
`release.py` 의 `RELEASE_OWNED` 로 제외, 경고·드라이런이 **파일 이름을 출력**.
스모크 11번 추가(임시 git 저장소 생성).

## 검증 중 잡은 버그

- 스모크 11번이 바로 값을 했다. 상태 두 글자를 자리(`line[3:]`)로 잘라내던
  구현이 `_git` 의 출력 `strip()` 때문에 **첫 줄만** 경로를 한 글자 밀어
  `ERSION` 을 내놨다. 나머지 줄은 멀쩡해 눈으로는 안 잡히는 종류다.

## 플레이북 반영 (부류급 교훈 3건)

- **4-13** OS 스케줄러 기본값이 실행을 막는다. "등록됐고 결과 0"은 실행됐다는
  뜻이 아니다. 검증은 조회가 아니라 죽여 보고 되살아나는지로.
- **5-15** 정상 경로에서도 켜지는 경고·플래그는 신호가 아니다. 도구가 스스로
  만드는 변화는 자기 판정에서 뺀다. 경고에는 목록을 같이 낸다.
- **5-16** 검증할 때 내가 보는 창구가 대상과 같은 세계인지 먼저 확인한다.
