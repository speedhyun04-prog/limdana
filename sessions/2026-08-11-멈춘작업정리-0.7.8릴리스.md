# [세션] 2026-08-11 멈춘 작업 순차 정리 + 0.7.8 릴리스

**프로젝트/주제**: 진행되다 멈춘 작업들을 전수 조사해 순서를 세우고, 앞쪽부터
차례로 처리. 도중에 설치판이 두 버전 뒤처져 있던 것과 결함 3건을 발견해 함께 해소.

## 결정 사항

- **작업 순서를 태스크 18개로 등록**하고 앞에서부터 처리한다(보스: "하나씩 순서
  잡아서 진행", 이후 "너가 판단해서 진행").
- **커밋·푸시는 작업 단위마다 자동**(보스 지시). 릴리스는 여전히 승인 필요.
  → 메모리 `git-push-autonomy`.
- **진단 로그는 지우지 않고 스위치로 남긴다.** 지우려던 그 로그가 이번에 결함
  두 건을 잡아냈다.
- **통화(보이스톡/페이스톡)는 HTTPS 선행.** 설계 문서만 쓰고 버튼은 계속 hidden.
  착수 시점 = 서버 이전 완료 후.
- **GPU 웹뷰 실험은 종결**(이 노트북은 off 고정, 재시도 금지).
- **P3 의 B2C 갈래는 우선순위 하향**(ext 사용자가 없어 실동작 영향 0).

## 다음 세션에서 필요한 맥락

- **릴리스**: `python installer\release.py --bump patch --notes-file notes.txt`.
  **한글 노트는 반드시 `--notes-file`**(UTF-8, `notes.txt` 는 gitignore 됨).
  태그는 자동 생성되고 `git push origin vX.Y.Z` 로 따로 밀어야 한다.
- **커밋 메시지에 큰따옴표가 있으면** PowerShell here-string 이 깨진다 →
  스크래치패드 파일에 쓰고 `git commit -F <파일>`.
- **PowerShell 에서 git 에 `2>&1` 을 붙이지 않는다** — 성공해도
  NativeCommandError 로 보인다.
- **버전 판정**: `http://127.0.0.1:8766/api/status`(브리지 version·owner),
  `http://127.0.0.1:8767/buildinfo`(셸, 개발기는 sha·dirty 가 빈 게 정상),
  `http://127.0.0.1:8765/api/health`(웹 서버 git_sha·started_at).
- **인스톨러 `/SILENT` 는 앱을 재기동하지 않는다.** 설치 후
  `Ahovye.exe --agent --autostart` 를 직접 띄워야 오브·단축키가 돌아온다.
  `-WindowStyle Hidden` 은 쓰지 않는다(첫 Qt 창 상속 사고 전례).
- **nav.js 핵심 계약**: `mark()` 는 인자를 받지 않는다. 기록 지점들이 서로를
  연쇄 호출하므로(applyView 가 orgOpen/workOpen/coOpen 을 부른다) 지금 DOM 을
  읽고 `setTimeout(0)` 으로 접고 직전과 다를 때만 쌓는다. 복원 순서는
  뷰 → 우측 컬럼 → 대화 → 작업 패널 고정. 검증은 `tests/test_nav_smoke.py`.
- **PLAYBOOK 신설**: 4-16(게시≠설치, 판정은 실행 중 프로세스에), 4-17(임시
  진단 코드는 배포 여부 확인 후 게이트로, 지우지 말고 끈다).
